## 📌 About the Project

**"Breaking Down the Race: Optimizing Formula 1 Data Analysis and Visualization for Strategic Decisions"**  
This project highlights my exploration into the world of Formula 1 data analytics. It includes data processing, statistical analysis, and interactive visualizations aimed at providing actionable insights for racing strategies.  

I use real F1 datasets to analyze aspects such as:
- Lap times
- Tire strategies
- Pit stop efficiency
- Weather impact
- Driver/team performance trends
